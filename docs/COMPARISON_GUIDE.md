# 跨文化过程对照

入口为 `/[locale]/compare`，首个专题为洪水、幸存与灾后的生活。
`data/comparisons/flood.json` 以具体文本中的叙事为单位，不把一个地区的异本合并成唯一版本。

- 每个事件有稳定 ID、对照环节、双语标题与内容、来源 ID 和段落定位。
- 故事的 events 数组保留本站依所选文本安排的阅读顺序。横向对照使用 step 对齐问题，不能改变原数组来迁就对照布局。
- 未交代的内容以 not-stated 表示，单独注记，不充当发生过的事件。不得从未收录推导整个传统不存在。
- tags 标出经过编辑确认的具体相似细节。共享标签表示所选文本有相似内容，不代表统计独立、历史同源或传播方向。
- 引文、原文转述和本站比较解释要可区分；不得从其他版本移入动机、人物或结局补齐格子。
- 第一组来源为《吉尔伽美什》XI（Kovacs）、《创世记》6–9（KJV）、《书库》1.7.2（Frazer）、《孟子》3A.4（南京博物院录文）。
- 中国列从已有水患出发，以治水与耕作为重点；没有强行补入舟船、灭世或重新造人。

## 地理背景

`/[locale]/earth` 介绍泛大陆、裂解与智人的出现，来源为 USGS 和 Smithsonian。
地质时间、文本及接触史、故事内部顺序分别解释。交互刻度以约三十万年除以所选时间窗，比例为 0.15% 或 30%。
不把泛大陆解释成神话同源或传播的证据，不把“盘古大陆”译名与盘古神话混同。

## 验证

运行 npm test、npm run validate、npm run audit、npm run lint、npm run build。
浏览器检查中英文、四列与两列、单环节与完整过程、按故事读、出处展开、条目返回、地图链接和深时刻度。
过程对照的筛选、阅读方式和聚焦环节保存在 URL；语言切换应保留它们。

2026-09-19 验证：15 项测试通过；500 条目校验零错误、零警告；内容审计仍有原有的 47 个单一来源条目；lint 和 1080 页生产构建通过。浏览器确认了两列筛选、退水环节的共享标签、来源展开、中英文状态保留、条目返回、中国叙事的原顺序、深时比例切换，以及 390px 宽度的响应式布局。直接带 #narratives 打开链接的定位也已检查。
