# 地图与叙事覆盖核对

核对日期：2026-09-23。候选来自用户提供的世界神话地图截图；它是发现线索，不是内容来源。以下检索覆盖 `data/traditions.json`、`data/entries` 与 `data/cosmogony`。文字提及不等于拥有独立入口，地区名称也不自动构成单一神话体系。

## 本批入库：罗马

- 地图入口 `roman`：罗马坐标 41.9, 12.5 仅作为这批拉丁文学材料的阅读入口；不填充现代国家范围，也不给宇宙创世虚构发生坐标。
- 双语条目：`janus`、`ovid-creation`。没有核准的本地配图，使用既有无图版式；不借用其他神祇图片冒充。
- 可比较叙事：`roman:metamorphoses`（四幕）、`roman:fasti-janus`（三幕）。同一作者、不同作品，两条轨道相互独立。
- 《变形记》止于卷一88行，不续接四时代与洪水；造物者未具名，人的起源保留原文的两种可能。
- 《岁时记》止于卷一144行；雅努斯从混沌到神职的自述不是罗马所有社群的统一宇宙信条。
- 仍未补齐：罗马建城传说、完整诸神谱系、不同地域的祭祀。两个条目只标志一个有内容的起步，不能称为“罗马神话已完整覆盖”。

来源核对：

1. [奥维德《变形记》卷一，Brookes More 译本（1922）](https://www.theoi.com/Text/OvidMetamorphoses1.html)，重点 5–88 行。
2. [温哥华岛大学 Ian Johnston《变形记》卷一译本](https://web.viu.ca/johnstoi/ovid/ovid1.htm)。这是同一原文的另一译本，不计作第二个独立古代见证。
3. [奥维德《岁时记》卷一，J. G. Frazer 译本](https://www.theoi.com/Text/OvidFasti1.html)，重点 89–144、171–188 行。
4. [大英博物馆钱币 1867,0212.84](https://www.britishmuseum.org/collection/object/C_1867-0212-84)：约公元前215–212年，罗马，雅努斯头像／船首。钱币证明图像使用，不能据此证明奥维德叙事在该年代已经存在。
5. [宾夕法尼亚大学博物馆：Roman Religion](https://www.penn.museum/sites/rome/religion/)，用于概览中的意大利、伊特鲁里亚与希腊文化接触背景。

## 现有大类仍需持续审核
